01

A release in. Curated files out.

One command takes each new GWAS Catalog release through five stages, inside one container.

02

One command.
Eight steps.

./agmp_gwas run takes the latest release all the way to files AGMP can import, and stops if anything looks wrong.

Fetch

Reads the latest release into memory.

Select

Keeps African and diaspora studies.

Resolve

Makes every variant ID an rsID.

Annotate

Adds genes, consequence and region.

Check

Stops before export if a check fails.

Export

Writes the files you choose.

Queue

Ranks unclear studies for curators.

Report

Lets you explore the release.
